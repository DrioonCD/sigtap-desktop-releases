## 📦 Sobre este repositório

Este repositório **não contém código-fonte** — ele existe só para hospedar as
**versões compiladas** (releases) do aplicativo, permitindo que o próprio app
verifique e baixe atualizações automaticamente.

Se você chegou aqui procurando o código do projeto, ele vive num repositório
separado e privado.

## ⬇️ Baixando o aplicativo

Vá até a aba **[Releases](../../releases)** deste repositório e baixe a versão mais recente.
Duas opções estão sempre disponíveis:

| Arquivo | Quando usar |
|---|---|
| `Consulta de dados SIGTAP - Instalador.exe` | Instalação normal no computador — cria atalho, abre mais rápido, atualiza sozinho. |
| `Consulta de dados SIGTAP.exe` (portable) | Não precisa instalar — roda de qualquer pasta, inclusive um pendrive. Atualização é manual. |

Nenhum dos dois exige conta ou cadastro público — o acesso é liberado individualmente pelo responsável pelo aplicativo.

## 🔄 Atualizações automáticas

A versão **instalada** verifica sozinha se existe uma versão mais nova aqui e
oferece pra baixar/instalar com um clique. A versão **portable** não se
autoatualiza (por natureza, ela não "vive" num lugar fixo) — para atualizar,
baixe o `.exe` mais recente aqui e substitua o antigo.

## ✨ Sobre o projeto

Criado para facilitar o dia a dia de quem trabalha com faturamento, auditoria
e gestão em saúde pública, consultando procedimentos, CIDs, CBOs, valores e
regras de compatibilidade da tabela SIGTAP sem precisar estar online.
